# Dataset

This directory is used for storing datasets required for AI-generated text detection.

## Expected Dataset Format

The training dataset should contain the following columns:

| Column | Description |
|---|---|
| text | The actual text or paragraph |
| label | Human-written or AI-generated category |

## Labels

- 0: Human-written
- 1: AI-generated

## Data Sources

Datasets will be collected from publicly available research datasets and academic text sources, subject to their licenses.

Dataset sources and references will be documented before training.

Large datasets are not stored directly in this GitHub repository.
