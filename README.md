# AcadCheck

### AI-Generated Text and Plagiarism Detection System for Academic Documents

AcadCheck is a machine learning-based academic integrity analysis platform designed for student assignments and scholarly research papers.

## Objectives

- Analyze linguistic patterns of human-written and AI-generated text.
- Develop a hybrid detection model using traditional ML and Deep Learning.
- Identify potentially plagiarized or similar text passages.
- Use Explainable AI to understand model predictions.
- Generate detailed academic document analysis reports.

## Technologies

- Python
- Machine Learning
- Natural Language Processing
- Scikit-learn
- Deep Learning
- Explainable AI
- React.js
- Flask

## Project Modules

1. AI-generated text detection
2. Text preprocessing
3. Plagiarism and similarity analysis
4. Explainable AI
5. Document processing
6. Web application

## Project Status

Currently under development.

## Disclaimer

AI detection and similarity scores are estimates. They should not be treated as definitive proof of academic misconduct.
